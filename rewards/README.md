# Trainer reward artwork

Upload PNG or WebP backgrounds and transparent frames here using Add file → Upload files, then commit the upload to main. Use a distinct filename for each design. Artwork in this repository is public, including images for rewards still in draft.

In PokeBotCommsHub → Streamer Dashboard → Reward manager, paste the uploaded file's raw.githubusercontent.com link, choose its name, type and stamp price, then save a draft and publish it when ready. Files must be at most 2 MB, from 16 to 4096 pixels per side. Frame images should have a transparent centre.

The reward manager validates the image and saves a link to that exact GitHub commit, preserving artwork already earned by trainers. No R2 bucket or GitHub token is needed in the website.
